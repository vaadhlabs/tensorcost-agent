# Security policy — unified-gpu-agent

## Reporting a vulnerability

Email **security@tensorcost.com** with a description of the issue and, if
possible, a minimal reproduction. Please do not open a public GitHub
issue for security-relevant findings.

We aim to acknowledge new reports within **3 business days** and to
ship a fix or mitigation within **30 days** of triage for high/critical
severity. For lower severities we will give you a target window during
triage. We are happy to credit reporters in the release notes unless
you prefer to stay anonymous.

## Scope

In scope:
- The agent source tree in this repository (`src/`, `main.py`,
  `Dockerfile`, helm chart, Terraform modules under `deploy/`).
- The published container images (`tensorcost/gpu-agent` on Docker Hub
  and the GHCR mirror).
- The SSM install path under `deploy/terraform/aws/ec2-agent/`.

Out of scope:
- Issues that require an attacker who already has root on the host the
  agent runs on (the agent's threat model assumes the host is honest).
- Findings against the dashboard backend or microfrontends — those
  live in a separate repository and have their own disclosure contact.

## Supply-chain integrity

Every published agent image is:

1. **Signed with cosign** in keyless OIDC mode. The signing identity is
   the GitHub Actions workflow that built it; it is verifiable against
   Sigstore's Fulcio root and recorded in the Rekor transparency log.
2. **Accompanied by a CycloneDX SBOM** generated with syft and attested
   with cosign as an in-toto predicate of type `cyclonedx`.
3. **Accompanied by a SLSA build provenance attestation** generated by
   `actions/attest-build-provenance`, binding the workflow ref + runner
   identity to the manifest digest.

To verify before pulling, run:

```sh
cosign verify docker.io/tensorcost/gpu-agent:<tag> \
  --certificate-identity-regexp '^https://github\.com/.+/gpu-agents/\.github/workflows/docker-publish\.yml@' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

See the **Verifying the image** section of the [README](./README.md) for
the full verification flow including SBOM and provenance inspection,
and the [`deploy/terraform/aws/ec2-agent`](./deploy/terraform/aws/ec2-agent/)
module's `agent_image_digest` variable for pinning a verified digest
into your fleet.
